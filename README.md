This project is a Selenium WebDriver automation framework built using Java, TestNG, and the Page Object Model (POM) to automate and validate key functionalities of the Luker India e-commerce website. The framework performs end-to-end UI testing, including cookie handling, page title and logo verification, broken link validation, user registration, login with Excel-driven test data, navigation across product categories, product selection, add-to-cart actions, and screenshot capture. It also handles multiple windows, scrolling, mouse/keyboard interactions, and waits, ensuring reliable automation of real user workflows. The project is designed to improve test maintainability, reusability, and scalability through structured page classes and utility support.
